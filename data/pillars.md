# Pillars

One hub per messaging pillar (`data/pillars/<slug>.md`), created by setup from
the Messaging pillars section of [Product](product.md). Each pillar hub states
its claim in one line and inclusion-links every post, draft and evergreen
template that carries it; this page inclusion-links the pillar hubs, so a
publication is always reachable from here.

``` bash
iwe find --included-by data/pillars/<slug>   # everything carrying one pillar
```
